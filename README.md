# retainium.github.io

The Retainium GitHub Pages org site, served at [games.retainium.ca](https://games.retainium.ca).

Each learning game is its own repo with Pages enabled and no custom domain, so GitHub serves it under this domain at `games.retainium.ca/<repo>/`, for example [Retainium/math-dungeons](https://github.com/Retainium/math-dungeons) at `games.retainium.ca/math-dungeons/`. To add a game, create its repo the same way and add a link to `index.html`.
